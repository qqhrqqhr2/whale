# Whale — WoW Fishing Assistant

[한국어](#한국어) | [English](#english)

## 한국어

**Whale**은 PC에서 월드 오브 워크래프트 낚시를 보조하기 위해 제작 중인 프로그램입니다.

### 소개
- 낚시 관련 반복 작업을 보조하기 위한 개인 프로젝트
- Windows PC용 프로그램 배포 예정
- 프로그램 사용 안내 및 변경 이력은 이 저장소에서 제공

> 현재 저장소는 배포 준비 단계입니다. 지원 기능, 호환되는 게임 버전 및 실행 조건은 첫 릴리스에서 안내합니다.

### 다운로드 및 설치
1. [Releases 페이지](https://github.com/qqhrqqhr2/whale/releases)에서 공개된 버전을 확인합니다.
2. 배포된 압축파일 또는 실행 파일을 다운로드합니다.
3. 해당 릴리스의 설치 및 실행 안내를 따릅니다.

릴리스가 아직 등록되지 않았다면 다운로드 가능한 버전이 없는 상태입니다.

### 오류 제보 및 기능 제안
오류, 개선 의견 또는 기능 요청은 [Issues](https://github.com/qqhrqqhr2/whale/issues)에 남겨주세요. 오류 발생 시 사용 중인 프로그램 버전과 재현 방법을 함께 작성하면 도움이 됩니다.

### 후원
프로젝트가 유용했다면 자발적인 후원으로 개발을 응원할 수 있습니다. 후원 링크는 추후 안내될 수 있습니다. 후원 여부와 관계없이 공개 버전의 이용 조건은 해당 릴리스의 안내를 따릅니다.

### 주의사항
- 이 프로젝트는 비공식 도구이며 Blizzard Entertainment와 제휴하거나 인증받지 않았습니다.
- 게임 자동화 도구 사용은 게임 및 서버의 운영 정책에 위배될 수 있으며 계정에 제재가 발생할 수 있습니다. 사용 전 해당 서비스의 이용약관을 확인하세요.
- 프로그램은 공개된 릴리스에서만 내려받는 것을 권장합니다.

## English

**Whale** is a PC utility project intended to assist with fishing-related tasks in World of Warcraft.

### Overview
- Personal project for assisting repetitive fishing-related tasks
- Windows PC releases planned
- Usage notes and release history will be maintained in this repository

> The repository is currently being prepared for distribution. Confirmed features, supported game versions, and runtime requirements will be documented with the first release.

### Download & Installation
1. Visit the [Releases page](https://github.com/qqhrqqhr2/whale/releases).
2. Download a published archive or executable, when available.
3. Follow the instructions provided with that release.

If no release is listed yet, there is no downloadable version available.

### Feedback & Bug Reports
Use [Issues](https://github.com/qqhrqqhr2/whale/issues) to report problems or suggest improvements. Please include the application version and reproduction steps when reporting a bug.
